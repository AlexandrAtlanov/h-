# baseline. Эталон для сравнения

Это точная копия `sample_submission.py` организаторов из папки «Данные»,
минимальный RAG из выборки по словам, embeddings, rerank и LLM.

Файл нельзя менять. Baseline должен оставаться тем решением, с которым
платформа сравнивает наш сабмит, любая правка обесценит локальные прогоны.

Ответы baseline кэшируются в `eval/reports/_cache/`, поэтому повторные
прогоны того же сета LLM не расходуют.

Если организаторы обновят sample_submission, замените файл здесь и в папке
«Данные», затем удалите кэш `eval/reports/_cache/baseline_*.jsonl`.
