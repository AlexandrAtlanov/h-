# h-

агентный RAG пайплайн для ответов по базе юридических документов.
Три модуля: `rag.py` — данные и поиск, `agent.py` — LLM-логика, `test.py` — тестовый прогон.

```
вопрос → планировщик → поиск (эмбеддинги + FAISS) → реранкер → критик/ответ
                    ↘ (допоиск при нехватке данных) ↗
```
